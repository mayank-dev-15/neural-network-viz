# neural-network-viz

![Language](https://img.shields.io/badge/Language-HTML/CSS/JS-green)

Interactive neural network builder with visual architecture designer, animated forward pass, and real-time training.

`machine-learning` `neural-networks` `visualization` `canvas` `ai`

---

## ✨ Features

- Visual neural network architecture builder
- Add/remove layers and adjust neurons per layer
- Animated forward pass propagation
- Click connections to adjust weights
- Activation functions: ReLU, Sigmoid, Tanh, Leaky ReLU, Softmax
- Training on XOR, AND, OR, circle classification datasets
- Real-time loss curve visualization
- Learning rate and epochs controls
- Network architecture presets
- Dark theme with glowing aesthetics

```bash
git clone https://github.com/mayank-dev-15/neural-network-viz.git
cd neural-network-viz
```

```bash
cd neural-network-viz
open index.html
```

---

## 💡 Usage

- Use + and - buttons to add/remove layers
- Click neurons to adjust count
- Click connections to edit weights
- Press Train to start training
- Watch the forward pass animation
- View real-time loss curve updates
