## About

**neural-network-viz** is a interactive neural network builder.

### Key Features

- Visual neural network architecture builder
- Add/remove layers and adjust neurons
- Animated forward pass propagation
- Click connections to adjust weights
- Activation functions: ReLU, Sigmoid, Tanh
- Training on XOR, AND, OR, circle datasets
- Real-time loss curve visualization
- Learning rate and epochs controls
- Network architecture presets
- Dark theme with glowing aesthetics

---

## Tech Stack

- HTML5 Canvas 2D
- Vanilla JavaScript
- CSS3
- Machine Learning math

---

## Controls & Usage

| Control | Action |
|---------|--------|
| `+ Layer` | Add layer |
| `- Layer` | Remove layer |
| `Click connection` | Edit weight |
| `Train` | Start training |
| `Reset` | Reset weights |
| `1-4` | Load dataset presets |
